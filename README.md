# Accessibility Friday

**Small contributions. Sustainable practice. Better accessibility.**

Accessibility Friday is my personal open-source contribution practice focused on improving accessibility in software through small, sustainable contributions.

Each Friday, I aim to spend approximately **10–45 minutes** contributing to an accessibility-related open-source project.

Contributions may include:

* Accessibility testing
* Functional and usability testing
* Bug reproduction and reporting
* Accessibility issue triage
* Python scripting or automation
* Test automation
* Documentation
* Project-management support
* Accessibility research
* Basic translation or localization
* Other small contributions that improve the accessibility of open-source software

## Why?

Accessibility work does not always require a large feature, a major pull request, or hours of coding.

A well-documented accessibility issue, reproducible bug report, useful test case, documentation improvement, or small automation improvement can help a project move forward.

Accessibility Friday is an experiment in making those contributions **consistent, sustainable, and visible**.

## The Rule

> **10–45 minutes is enough.**

Some Fridays may result in a pull request.

Some may result in an issue.

Some may involve testing, research, documentation, translation, or project planning.

Some Fridays may simply be spent learning about a project.

The goal is not volume.

The goal is **consistent contribution without burning out**.
